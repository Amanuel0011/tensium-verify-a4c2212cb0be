# Tensium Verify

This repository contains a small verification project for the `tensium-verify-8f655edb0fbb` codebase.

It includes a minimal front-end and a small Python verification helper to demonstrate a working repository structure.

## Files

- `index.html` — a simple UI shell
- `style.css` — styles for the interface
- `app.js` — browser-side logic
- `verify.py` — Python verification utility
- `README.md` — project notes

## Quick start

### Browser
Open `index.html` in a browser.

### Python
```bash
python3 verify.py
```
